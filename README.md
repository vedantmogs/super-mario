## 🚀 About

**Super Mario Game** is a retro-styled browser platformer inspired by the iconic Super Mario universe. Built with HTML, CSS, and JavaScript, it delivers a nostalgic gameplay experience that runs directly in any modern browser.

> A simple, fun, and polished Mario-inspired adventure for players of all ages.

## ✨ Features

- Retro platformer look and feel
- Smooth browser-based controls
- Jump, run, and explore pixel-style levels
- Responsive game layout for desktop and mobile browsers
- Lightweight and easy to launch instantly

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Browser-native audio and animation

## 🎮 Gameplay

Players control Mario to run across platforms, avoid obstacles, and reach the goal. The game is designed for short, engaging sessions with classic platformer mechanics.

### What to expect

- Retro pixel-inspired visuals
- Classic platforming movement
- Simple level design for instant play
- Clean UI and polished transitions

## ⚙️ Installation & Setup

1. Clone or download the repository.
2. Open `index.html` in your browser.

```bash
git clone https://github.com/vedantmogs/super-mario-game.git
cd super-mario-game
```

3. Launch the project in any modern browser.
4. No build tools or dependencies required.

> For best results, use Chrome, Edge, Firefox, or Safari.

## 🎮 Controls

- **Arrow Left / A**: Move left
- **Arrow Right / D**: Move right
- **Space / W / Arrow Up**: Jump
- **R**: Restart level (if available)
